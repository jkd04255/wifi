# v1.6 기준 동작 수동 QA

현재 **테스트 수행 결과 미기록**. 아래는 검증 대상이며 자동으로 통과 처리하지 않는다.

- [ ] HTML 첫 화면에 집 구조 도면 편집 화면만 보이는지
- [ ] 공유기 설치 위치가 실내 내부로 제한되는지
- [ ] 선 추가, 사각형, 선 일부 지우개가 의도대로 동작하는지
- [ ] 중요도 빨강 +100 / 초록 0 / 파랑 -100을 편집할 수 있는지
- [ ] 방 외부 중요도 정리 버튼이 실행되는지
- [ ] 콘크리트 벽과 2.4/5GHz 예측 모델이 반영되는지
- [ ] 평수 스케일 및 도면 x-z 좌표, 공유기 높이 y가 표시되는지
- [ ] Apply → RSSI 히트맵 및 결과 확인이 동작하는지
- [ ] 중요도 가중치 반영/미반영 비교가 되는지
- [ ] '최고의 위치 찾기' 버튼이 실제 실내 후보로 이동시키는지
- [ ] 모바일 화면에서 캔버스/버튼 사용이 가능한지
- [ ] Pages 정적 환경에서 외부 API 없이 가능한 부분/불가능한 부분을 표시했는지

QA 결과에는 브라우저·날짜·테스트 재현 단계·스크린샷을 기록한다. GATE 1은 실제 Pages 접속과 이 체크리스트 확인 후에만 완료 처리한다.
