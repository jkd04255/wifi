# Wiplan 나무 방문 기능 · RSSI 엔진 및 사용자 QA

## 요구사항과 기본값
- 첫 사용자 지시에 따라 **나무 방문 기본 너비는 0.90m(900mm)** 입니다. 별도 프롬프트의 0.80m 기본값과 충돌하므로 900mm를 적용합니다.
- 방문은 1단계 도면의 **'문 추가'** 도구로만 실제 콘크리트 벽 위에 설치할 수 있습니다. 벽에 가까운 지점을 선택하면 벽의 방향에 맞춰 자동 정렬하며, 설치 위치를 벽 위 비율(%) 입력으로 이동하고 너비를 0.4~2.0m 범위에서 조절할 수 있습니다.
- 같은 벽의 다른 문과 겹칠 수 없습니다. 선택 문을 다시 클릭하면 열림/닫힘을 전환합니다. 각 문에는 삭제와 Undo가 있습니다.
- **닫힌 목재 방문의 고정 추가 감쇠량:** 2.4GHz 4 dB, 5GHz 6 dB. 열린 문은 문 자체의 추가 손실 0 dB. 실제 속도나 실측 모델의 정확도 보장이 아니라 초기 시뮬레이션 값입니다.

## 계산 엔진
- `layout.walls`는 편집/JSON 복원 시 **원본 기준 벽 선분**을 보존합니다. `layout.doors`는 실제로 벽의 어느 구간을 대체하는지 지정합니다.
- `WifiEngine.effectiveWalls(layout)`가 부모 벽에서 나무문 구간을 **절단한 콘크리트 벽 선분 목록**을 생성합니다. **RSSI 전파 경로·화면 그리기·최적화 벽 충돌·좌우상하 위치 판단**에서 이 목록을 사용하므로 같은 물리 구간에 콘크리트 감쇠와 문 감쇠를 동시에 부과하지 않습니다.
- `WifiEngine.value`는 기존 경로손실·콘크리트 감쇠·2.4GHz CAMPUSRSSI OPEN/GENERAL/DENSE·Robust maximin·벽 부착 방향 시험 모델을 그대로 보존하면서 닫힌 문 교차당만 4/6dB를 차감합니다.
- RSSI(dBm)와 추가 감쇠량(dB)은 구분합니다. `value(...,true)`의 `walls`, `doors`, `wallLossDb`, `doorLossDb`, `totalObstacleLossDb`를 별도로 반환합니다.
- 교차 판단은 **도면의 XZ 좌표**에서만 수행하며, 확대/축소된 화면 픽셀 좌표에 의존하지 않습니다. 문 끝점 및 벽 경계는 동일한 선분 교차 알고리즘의 열린 경계로 처리해 중복 차감을 방지합니다.

## 쉬운 화면
- 도면은 콘크리트 벽(짙은 선), 닫힌 나무 방문(갈색 가로막), 열린 문(틈 + 열린 문짝)을 구분합니다.
- 도면에서 선택한 문이 있으면 문 폭과 벽 위 위치를 수정하거나 열고 닫고 삭제할 수 있습니다.
- ④ 신호 분석의 **'나무 방문 열림·닫힘'** 패널은 문별 상태를 변경하면 기존 히트맵을 **자동 재계산**합니다. 같은 수신 지점에서 모든 방문을 열었을 때/닫았을 때의 예측 점수와 dBm, 차이 dB를 비교합니다.
- 고급 보기에서 수신 지점의 콘크리트 벽 통과 횟수, 닫힌 나무문 통과 횟수, 각 감쇠량 및 전체 장애물 감쇠량을 구분합니다.
- **'위치 판단 · 좌/우/상/하 벽 거리'** 버튼은 선택한 수신 지점에서 벽까지 축방향 거리를 m로 제시하며 문으로 대체된 틈은 콘크리트 벽으로 계산하지 않습니다.
- 넓은 추천 영역, 비교 카드, 설명 `i` 버튼의 원형 디자인을 2px/3px의 각진 XP 스타일로 바꿨습니다.

## JSON 데이터 계약
- 기존 `schemaVersion: 1.1` 파일을 유지합니다. `doors`가 없는 기존 JSON도 정상 복원하며 원래 벽/공유기/핀 정보는 임의로 바꾸지 않습니다.
- 새 `doors` 항목: `{id, type:'wood', state:'open'|'closed', wallId, x1,z1,x2,z2, widthM,centerT}`.
- 불러오기 전 문 타입, 상태, ID 중복, 부모 벽 존재, 좌표 유효성·벽 선분 정렬·실제 길이·다른 문과 겹침을 검증합니다. 검증 실패 시 **기존 도면을 변경하지 않습니다**.

## 검증 범위
- 장애물 없음, 문이 없는 도면의 기존 RSSI 유지.
- 닫힌 방문 1개 교차 2.4GHz 4dB/5GHz 6dB, 2개 교차 8dB/12dB.
- 열린 방문 0dB, 문을 통과하지 않는 경로에서 추가 감쇠 없음, 경계·중복 교차 및 콘크리트와 중복 감쇠 없음.
- 실제 UI 문 추가·폭/위치 편집·상태 변경·삭제·Undo, JSON 저장/복원 및 비정상 JSON 보호, 분석 재계산.
- 실측 안테나/목재문 수치 검증, 실제 Windows PC의 GUI 실행 및 고밀도 건물에서의 회절·다중경로 재현은 **미검증**.
