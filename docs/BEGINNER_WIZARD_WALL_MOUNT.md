# Wiplan 일반 사용자 4단계 인터페이스 및 벽 부착 시험 모델

## 화면 구성

1. **도면 그리기** — 도구와 신호 세기 핀(4/3/2/1/0칸 = 64/42/27/9/0점)을 배치합니다. 상단·하단 드래그 손잡이와 +/− 버튼으로 도면 **화면 높이만** 조절합니다. 도면 XZ 실측 좌표/면적/벽 형상은 변경되지 않습니다.
2. **공유기 설정** — 일반(2.4GHz/20dBm/0dBi)과 고급(주파수, 송신출력, 안테나 이득, 5GHz 거리 감쇠 지수)을 선택합니다. 자유 배치 또는 벽 부착을 지정합니다.
3. **높이 설정** — **공유기 높이와 수신기(스마트폰) 높이를 독립적으로 선택**합니다. 공유기는 0/0.3/1/1.2/1.6/2.2m, 스마트폰은 0/0.3/0.7/1/1.2/1.6m 프리셋 및 각자 고급 직접 입력(0 이상)을 제공합니다. 공유기 1.2m, 수신기 1m가 기존 기본값이며 실제 천장·벽 높이에 대한 상한 모델은 없습니다.
4. **신호 분석** — 일반 보기에는 예측 RSSI를 0~100점으로 변환한 지표를 표시합니다. 고급 보기에서는 원래의 dBm/RSSI, 벽 통과 감쇠 및 CAMPUSRSSI 상세 모델을 다시 볼 수 있습니다. 선택 위치의 좌·우·상·하 벽 거리도 조회할 수 있습니다.

독립된 상단 탭 및 XP 메뉴는 기존 작업과 호환하기 위해 네 단계 사이의 직접 이동을 허용합니다. **순차 사용**은 ①→②→③→④의 '다음' 버튼입니다.

## 100점 만점 점수: 통신 속도 점수가 아님

- 개별 지점: `Q_i = clamp((RSSI_i+90)/55 × 100, 0,100)`.
- 일반 화면의 **평균 신호 점수**: `mean(Q_i)` (공간 격자에 대해 동일 가중치).
- **중요도 반영 품질**: `Σ(w_i×Q_i)/Σw_i`. 빨강 중요도 +100% → 2배, 초록 0% → 1배, 파랑 -100% → 0배.
- **우수 커버리지**: 예측 RSSI가 −67dBm 이상인 격자 비율(%).
- **취약 공간 비율**: 예측 RSSI가 −75dBm 미만인 격자 비율(%).
- 같은 수치를 다른 단위로 표현하는 것입니다. 100점이라고 해서 전송속도·온라인 품질·실제 측정값의 정확도를 보장하지 않습니다.
- 상단 도움말 `i`는 hover/focus로 짧은 정보, 클릭 시 공식 및 문맥을 안내합니다. 고급 화면의 전문 용어집에는 RSSI, dBm, 안테나 이득, 경로손실, Robust, feasible, J, MAE 등 20개 항목의 계산/의미를 적었습니다.

## 벽 부착은 위치 제약 + 미검증 방향 패턴을 구분

- 공유기 설치 방식이 `wall`이면, 도면에 콘크리트 벽 선분이 반드시 있어야 진행할 수 있습니다.
- 사용자가 방향을 선택하지 않습니다. 프로그램이 **공유기 지정 위치와 가장 가까운 벽**을 먼저 선정하고, 해당 벽의 양쪽 법선 방향에서 (1) 원래 공유기 위치와 같은 쪽 (2) 중요 신호 핀 위치 (3) 도면 내부의 면적 표본 5×5개를 고려해 상대적으로 적합한 부착면을 추정합니다. 공유기는 선택된 벽 선분의 **법선 방향 약 0.04m**에 설치됩니다. 도면에 벽이 없으면 진행을 차단합니다.
- 평면 벽의 앞·뒤는 위 휴리스틱으로 판정합니다. **외벽·실내벽의 실제 앞뒤, 안테나 내부 구조, 열린 도면의 실내외 구분을 정확히 알 수는 없습니다.** 사용자가 벽을 따라 공유기 위치를 옮기면 그 위치를 기준으로 자동 재판정하며, 2.4GHz 최적화의 각 벽 후보에서도 해당 후보의 방향을 개별적으로 산정합니다.
- 가정한 방향 패턴 손실: `4×(1−cos θ)` dB, θ는 자동 추정된 벽 법선 방향과 수신 방향 사이 각도. 앞쪽 0, 측면 약 4, 뒤쪽 최대 8dB입니다. **실제 공유기/안테나의 측정 패턴이 아닙니다.** 콘크리트 벽 교차 감쇠와 더해지는 예비 UX/연구 시나리오로만 사용합니다.
- 벽 부착에서는 최적 배치 후보도 실제 벽 선분을 따라 생성하며, 방향과 부착 가능성을 확인합니다. 배치가 불가능하면 빈 공간 후보를 우회적으로 추천하지 않습니다.
- 장비 기종에 따라 벽/천장 설치용 내부 안테나가 달라지므로 실제 제품 제조사 권장 방향, 벽 재질, 설치환경에서의 실측을 확인해야 합니다. 참고:
  - https://www.cisco.com/c/en/us/products/collateral/wireless/catalyst-9100ax-access-points/guide-c07-742311.html
  - https://arubanetworking.hpe.com/techdocs/VSG/docs/010-campus-design/esp-campus-design-047-rf-design/
- `dBi` 안테나 이득은 전력을 증폭하는 장치가 아니라 전파의 방향별 집중 정도입니다. 별도 증폭기와 혼동하지 않습니다.

## 위치 판단

히트맵에서 선택한 XZ 위치를 기준으로 좌·우·상·하의 **축 방향 광선**과 도면의 콘크리트 벽 선분의 교차점 중 가장 가까운 거리(m)를 표시합니다. 해당 방향에 벽이 없으면 '도면 경계(벽 없음)'로 구분합니다. 문/장애물 높이 및 실제 3차원 보행거리는 계산하지 않습니다.

## 데이터 계약 및 제한

- 모델 입력은 기존 `schemaVersion 1.1` JSON을 유지합니다. 기존 JSON의 `router.mountMode`가 없으면 자유 배치로 취급합니다. 벽 부착은 `mountMode=wall`과 자동 산정된 `mountFace`, `mountNormalX/Z`, `wallId`를 보존합니다. **기존 JSON의 mountFace 방향은 벽 좌표에 맞춰 자동 재산정합니다.** 공유기 높이는 `router.y`, 스마트폰 높이는 `receiverY`로 서로 분리하여 보존합니다.
- 불러오기 전에 마운트 모드와 과거 형식의 면 방향값을 검증하고 벽 부착은 실제 벽 근처로 자동 재정렬합니다. 불가능하거나 잘못된 선택값은 **이전 도면을 덮어쓰기 전에 거부**합니다.
- 2.4GHz OPEN(n1.6538, 콘크리트 6.28dB), GENERAL(n2.0011, 6.8491dB), DENSE(n2.3784, 7.21dB)는 연구값 그대로입니다. 표시명은 신호 원활/중간/혼잡.
- **Robust maximin**, 핀별 요구점수 하드 제약, Top 3, 기존 중요도 점수 계산 유지. 5GHz CAMPUSRSSI 보정 없음, M3 잔차보정 OFF, LAN/케이블 미고려, 높이 제한 없음.
- EXE는 **Windows x64용 브라우저 기반 오프라인 실행 파일**로 실제 Windows XP 운영체제용이 아니며 코드 서명/실제 Windows PC 실행 검증은 별도입니다.
